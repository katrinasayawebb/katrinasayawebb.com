This is an example of a LEARN note. Write in plain Markdown: paragraphs, **bold**, [links](https://katrinasayawebb.com), and lists.

## A section heading

- One point
- Another point

Inline `code` and code blocks both work:

```python
import pandas as pd

df = pd.read_csv("export.csv", skiprows=1)
print(df.head())
```

> A pull quote or an aside reads like this.
